## Featured projects

### [SAM3 Label Studio Toolkit](https://github.com/Dan5N/sam3-labelstudio-toolkit)

A self-hosted SAM 3 inference and fine-tuning toolkit for Label Studio, including prompt-aware segmentation, RLE mask output, training jobs, checkpoints, metrics, authentication, and audit records.

### [Defect Representation & Synthesis](https://github.com/Dan5N/defect-representation-synthesis)

Research and engineering infrastructure for instance-level defect representation learning, retrieval, prototype discovery, and representation-guided synthesis on GPU-enabled environments.

### [Photography Studio](https://github.com/Dan5N/PhotographyStudio)

A staff-facing photography workflow application built with Next.js, tRPC, Prisma, and PostgreSQL, with Docker deployment, migrations, authentication, integration tests, browser tests, and capacity testing.

### [Tlias Management System](https://github.com/Dan5N/Tlias-managemnet-system)

A Java and Vue employee management system demonstrating Spring Boot, MyBatis, JWT authentication, MySQL, Docker Compose, and separated frontend/backend deployment.
